## Featured Project

### 🛡️ Multi-Modal Phishing Email & Threat Detection System

A threat-detection system designed to identify sophisticated phishing and social-engineering emails that may bypass conventional heuristic filters.

**Input:** Raw email payloads including headers, body text, structural HTML, and embedded URLs.

**Output:** Threat probability score, threat-category classification, and explainable indicators.

**Architecture:** Transformer-based text representations using **DeBERTa/RoBERTa**, contextual feature extraction, and downstream classification.

#### Highlights

- Built an end-to-end data preprocessing pipeline
- Fine-tuned and evaluated Transformer-based models against baseline classifiers
- Worked with curated public benchmark datasets, including Nazario and Enron
- Built a prototype inference API with FastAPI
- Investigated false positives in legitimate promotional emails
- Addressed variable-length HTML noise during tokenization
- Optimized model evaluation and inference workflows
