## Current Work

### 🛡️ Multi-Modal Phishing Email & Threat Detection System

**Status:** `Model Evaluation & API Optimization`

A threat-detection system designed to identify sophisticated phishing
attacks and social-engineering emails that may bypass conventional
heuristic filters.

**Input:** Raw email payloads including headers, body text, structural
HTML, and embedded URLs.

**Output:** Threat probability score, threat-category classification,
and explainable indicators.

**Architecture:** Transformer-based text representation using
**DeBERTa/RoBERTa**, combined with contextual feature extraction and
downstream classification.
